# Gyanesh Sharma — Portfolio

A responsive, single-page portfolio for Gyanesh Sharma, Principal Software Engineer at NielsenIQ. It presents his professional experience, skills, education, achievements, and contact information. AI and LLM engineering are part of his experience and skill set, not the subject of the site.

## Run locally

Requirements: Node.js 20.19+ or 22.12+.

```bash
npm ci
npm start
```

Open http://localhost:4200.

## Build

```bash
npm run build
```

## Portfolio content

- Update experience, skills, impact metrics, and awards in `src/app/app.component.ts`.
- Update section content and contact links in `src/app/app.component.html`.
- The home hero uses the portrait in an animated career-profile graphic. Provide a naturally smiling, direct-gaze photo to change the expression while keeping the result authentic.
- The page uses CSS animations and scroll-triggered reveals, with reduced-motion support.
- This is a static frontend; no backend is required.
